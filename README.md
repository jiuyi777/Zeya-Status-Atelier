一句话简介：在同一个 SillyTavern 工坊里制作“可点击的开场白主页”和“由 AI 随剧情填写的动态状态栏”。

它不是设计图生成器，也不是把图片上传到 GitHub。它会生成可以真正导入和继续编辑的 HTML、CSS、正则 JSON 与世界书 JSON。

## 它能做什么

- **制作开场白主页**：自动读取当前角色卡的额外问候语，建立作品目录，编辑标题、作者、推荐模型、推荐预设、作品简介和配色；玩家点击“进入”后切换到真实开场白。
- **识别并绑定世界线**：从角色卡内嵌或已绑定世界书中读取真实线路条目；存在可切换 UID 时，进入开场白可同步启用目标线路。
- **制作动态状态栏**：从 20 套自由面板与 20 套类型状态栏中一键换整套，也可继续修改字段名称、类型和 AI 填写要求。
- **自由组装视觉**：29 种组件结构、20 种自由面板材质、50 套外观主题和 24 套色卡可继续独立组装。
- **使用真实媒体**：绑定当前角色头像、当前 User 头像或图片 URL，并可加入封面图和手动播放的音乐链接。
- **生成与安装成品**：下载世界书与正则 JSON，或直接应用到当前角色 / 全局；工坊配置也可以备份和恢复。
- **测试 AI 输出**：使用酒馆当前模型、Key 与预设发起一次真实测试，并检查返回的状态字段是否完整。

状态栏设置中只定义“好感度应该怎么填”“内心独白应该写什么”，不会要求用户手工维护当前数值。真正的好感度、地点、余额、帖子、日记或任务进度由 AI 每轮根据剧情生成，再由正则显示成界面。

仓库另附四套可直接导入的开场白主页和五十套“世界书 + 正则”通用状态栏。可先阅读 [功能简介](docs/项目简介.md)，第一次使用请直接打开 [完整新手教程](docs/新手教程.md)，其中包含安装、主页制作、状态栏制作、头像与音乐、AI 测试、导入和故障排查。

## 最重要的区别

下面这些是固定定义，由你在插件设置里修改：

- 字段名称，例如“好感度”“信任值”“可用资金”“内心想法”；
- AI 填写要求，例如“填写 0–100 的整数”“第一人称写 50–150 字日记”；
- 切换页名称，例如“角色一 / 角色二”“现实 / 回忆”；
- 状态栏标题、排版和视觉主题；
- 开场白的标题、人物、故事简介和备注。

下面这些不是固定设置，插件中没有输入框，由 AI 每轮根据剧情填写：

- 当前好感数值与本轮变化；
- 当前时间、地点和天气；
- 角色余额；
- 日记正文、内心想法、近期记忆与下一步行动。

## 安装

### 本地安装

1. 解压插件 ZIP。
2. 将 `status-atelier` 文件夹放到：

   ```text
   SillyTavern/public/scripts/extensions/third-party/status-atelier
   ```

3. 确认这个目录下直接能看到 `manifest.json`、`index.js` 和 `settings.html`，不要多套一层同名文件夹。
4. 完全刷新 SillyTavern。
5. 打开“扩展设置”，找到“九一 · 正则状态工坊”。

### GitHub 安装

在 SillyTavern 的“安装扩展”中粘贴：

```text
https://github.com/jiuyi777/Zeya-Status-Atelier
```

安装后刷新页面，并在“扩展设置”里打开“九一 · 正则状态工坊”。

## 第一次使用

### 1. 按用途选择模板

内置“攻略关系”“开局信息”“大世界 NPC”“生存数值”四类起始模板。它们只是可编辑的字段组合，不限制角色数量：攻略模板可含好感度和内心独白；大世界模板更适合地点、事件和 NPC；生存模板可显示生命值、体力等数字。

### 2. 修改切换页

每行写法：

```text
按钮名称|这个人物或视角的 AI 要求
```

例如：

```text
喻生|谨慎克制，掌控家族财富，对用户有无法克制的贪恋
喻黎|困在老城区打零工，逐渐陷入无人相信他的困顿
```

这里的描述会写进 AI 输出规则；它不是本轮剧情值。

### 3. 修改字段

每行写法：

```text
显示名称|AI 填写要求|类型
```

例如：

```text
好感度|填写0到100之间的整数，只写数字|progress
本轮变化|填写本轮好感变化，例如+3或-1|number
可用资金|填写具体金额并带货币符号|currency
内心想法|第一人称填写没有说出口的真实想法|long
```

可用类型：

- `text`：普通文字；
- `long`：跨整行显示的长文本；
- `number`：数字或变化值；
- `progress`：0–100 的动态进度条；
- `currency`：金额。

### 4. 让 AI 使用规则

当前角色推荐直接使用“一键应用到当前角色”：

- 插件会创建或更新该角色专用的“九一-状态栏-…”辅助世界书，把 AI 输出规则写成常驻条目并绑定当前角色；
- 同时创建或更新当前角色局部正则，负责把 AI 输出的状态区块渲染成选择的界面；
- 再次点击只更新同一世界书条目和同一局部正则，不会无限复制。

“兼容模式”只用于不能使用角色世界书的旧环境；正常一键应用后不需要开启，避免同一规则重复进入提示词。

### 5. 生成正则

- “下载正则 JSON”：生成一个可以手动导入 SillyTavern 正则扩展的文件；
- “一键应用到当前角色”：同时安装世界书 AI 输出规则与当前角色局部正则；两边都确认写入后才会提示完成。

生成的正则会捕获整个状态区块，再按当前设置中的字段顺序解析。状态页按钮只切换显示，不会修改 AI 原文。

## AI 实际输出示例

假设使用两个角色页，AI 每轮会生成类似：

```text
<zeya_status>
[Shared|9月14日|21:40|小雨]
[View1|旧城区书店|55|+3|克制|第一位角色的动态想法|动态观察|动态记忆|动态计划]
[View2|老城区修车铺|18|-1|疲惫|第二位角色的动态想法|动态观察|动态记忆|动态计划]
</zeya_status>
```

其中 `View1 / View2` 是稳定记录键；界面按钮显示的是你填写的人物名称。示例数值只用于解释协议，不会保存在插件设置中。

## 开场白主页与导航

插件可以生成四套开场白主页：

- 01 古典对称；
- 03 复古报刊；
- 04 中轴时间线；
- 05 构成编辑。

四张设计方向图存放在 [`docs/previews`](docs/previews)；它们是版式方向图，最终聊天中的文字和条目数量来自你填写的模板。

主页固定资料包括标题、小副标题、作者、推荐模型、推荐预设和作品简介。推荐模型与推荐预设是多行输入，可以一行填写一个名称。目录由重复的 `[Opening|...]` 记录组成，所以 2 条、8 条、10 条都能自动显示；也可以直接读取当前角色卡全部开场白并按顺序生成。标题和小副标题为空或仍是默认值时可由 AI 补全；已经手写的作品简介不会被“全部重新生成”覆盖。字体以及主页底图、内容卡片、标题文字、推荐信息、简介底色、进入按钮和辅助色均可分别修改，也可一键使用推荐色卡。

世界线定义绑定的是“具体世界书 + 具体条目 UID”，不是整本世界书。读取角色卡时，插件会从内嵌和已绑定世界书中提取“罪人线、少年线”等真实线路前缀，自动建立或复用世界线并绑定对应 UID；每条开场仍可在弹窗里查看和调整绑定。进入某条开场白时，主页正则会启用该路线绑定的条目、关闭其他已定义路线的条目，并处理该开场白额外勾选的条目。最终主页会显示世界线介绍和每条开场的线路标签。

目录简介可用酒馆当前主 API 与当前预设生成，也可使用自填的 OpenAI 兼容接口，或完全手写。额外接口密钥只保存在本机插件设置中，导出工坊配置时不会带出。

“复制主页标记”只会复制 `【主页】`，把它单独放进角色卡的主开场白即可；“下载主页正则 JSON”或“一键安装”会把当前填写的标题、简介、目录、样式、跳转目标和 UID 绑定全部封装进正则。

0.8.7 起不再需要 `<opening_home>` 标签，也不会把设置数据塞进主开场白。旧版已经导出的正则不会自动改变，需要在工坊里重新下载或重新安装一次。

0.8.6 起，“进入”按钮会优先使用酒馆助手已经公开并用于前端切换开场白的 `setChatMessages` 接口，同时切换所选线路绑定的 UID；旧酒馆环境才回退到原生 swipe 与 Slash 命令。

0.8.8 起，主页会兼容酒馆助手直接注入到前端作用域的全局接口，并按官方示例直接调用 `setChatMessages([{ message_id: 0, swipe_id }])`。即使某张卡的世界书 UID 绑定失败，也会继续切换额外开场白，不再让绑定错误拦住“进入”。

0.8.9 起，正则仍然只匹配主开场白中的 `【主页】`，但替换结果会包在酒馆助手可执行的 `html` 代码块中。裸 HTML 虽然能显示页面，却不会执行其中的按钮脚本；代码块渲染会创建真正可交互的前端界面。主页模板会同步套用各自的字体与完整配色，作品资料、世界线介绍和额外问候语目录也可以独立折叠。

0.8.10 补齐酒馆助手 iframe 渲染器要求的完整 `<body>...</body>` 文档结构，并同时覆盖用户与 AI 楼层。缺少 body 的 fenced HTML 只会显示为普通代码块，不能识别成可交互界面。

0.8.11 起，世界书切换优先使用酒馆助手现行的 `updateWorldbookWith`，并保留旧 `setLorebookEntries` 与 Slash 回退。角色卡内嵌 lorebook 仍可用于识别线路，但只有已经导入并绑定为真实世界书文件的 UID 才会显示为可切换绑定；移动端弹窗同时补齐安全区和 44px 触摸尺寸。

0.9.0 起，状态栏不再只是同一骨架换皮：新增人物名片、种草动态、论坛主题、聊天会话、影像拼贴、音乐播放、任务地图、案件卷宗和自由组件板 9 种结构，以及 12 套独立色卡。头像可以绑定当前角色、当前 User、直接 URL 或不使用头像，并可加入封面图片与手动播放的音频链接；“真实测试一次 AI 生成”会使用酒馆当前模型与 Key，并在返回后校验所有状态字段是否完整。

0.9.1 起，魔棒入口可以一键生成并复制“开场白一览”：AI 只写短标题和简介，摘录段落由插件从角色卡原文逐字选取；该工具不会保存结果，也不会改动主页、正则或角色卡。同一弹窗中也能选择 50 套状态栏并直接覆盖当前角色的局部正则，无需下载后再次导入。每张角色卡分别保存自己的主页与线路草稿。

0.9.2 起，开场白主页从四套扩展为十二套真正不同的结构：新增古风卷轴、美式杂志、拼贴手账、黑银档案、水色玻璃、动态字构、赤黑电影海报和留白构成。模板不只更换配色，还分别改变报头、资料栏、简介、线路、目录卡片与按钮形态；其中后三套加入斜向字构、竖排侧题、海报侧栏和非对称留白，并保留手机单列回退。状态栏工作区同时提供可直接点选的 50 套外观、24 套色卡与 9 种结构，选择时原位更新预览，不再重复重建整个选项区；音乐结构增加唱片视觉，字段名称和内容保持可编辑。

0.9.3 起，“生成并复制开场白一览”会优先读取当前角色已经编辑好的短标题、线路标签和路线简介，只让 AI 补缺失项，并在复制结果中标出真实线路；作品总简介为空时，会结合当前角色设定、场景、主开场白和世界书背景生成。世界线介绍始终为可选项，留空时主页不再显示伪造的占位介绍。

0.9.6 起，魔棒的“直接制作状态栏”默认进入自由组件版，可直接选择 9 种组件结构、50 套外观、24 套折叠色卡和 18 个带变形效果的装饰 Logo，并查看真实实时预览。组件结构会更换整副骨架，外观会更换视觉语言，色卡只更新颜色；三者分开组装。高频切换不重建整张预览，移动端弹窗也限制在安全区内滚动。

魔棒中现在分别显示“直接制作开场白”和“直接制作状态栏”。快捷弹窗里的主页外观默认折叠并优先显示收藏，未收藏外观需要主动展开；关闭快捷编辑器时会立即保存当前角色草稿。

仓库中的 `starter-packs/开场白主页` 已放好四套成品。每套包含一个正则 JSON 和一个可编辑模板。

### 读取角色卡现有开场白

辅助导航与状态规则分开。

它读取当前角色卡和聊天中真实存在的主开场白及备用开场白。每条开场白可以编辑：

- 导航标题；
- 涉及人物 / 视角；
- 故事简介；
- 备注 / 关键词。

点击“切换并定位”会调用 SillyTavern 原生开场白 swipe，并滚动到聊天第 1 条。已经聊了很多轮以后切换开场白，会改变当前聊天历史的开端，这是酒馆原生行为。

## 五十套通用状态栏成品

`starter-packs/通用状态栏` 中的每套成品都包含：

- 一个可直接导入的世界书 JSON，要求 AI 每轮按剧情动态输出；
- 一个对应标签的正则 JSON，负责美化、人物或视角切换和进度条；

## 常见问题

### 为什么设置里没有好感度数字输入框？

因为数字必须由 AI 结合当前剧情填写。设置页只定义“这个字段叫好感度，并要求 AI 填写 0–100 的整数”。

### 为什么预览写着“AI动态填写”？

预览只确认字段数量、切换页和排版，没有冒充当前剧情数据。实际聊天中会显示 AI 回复中的真实值。

### 状态栏没有出现

依次检查：

1. AI 回复原文是否包含设置中的输出标签；
2. 已生成的正则是否启用；
3. AI 输出记录是否保持字段顺序和英文竖线；
4. 是否同时启用了会抢先处理同一标签的旧正则。

### 怎么定位要读取的角色卡？

不需要填写角色卡文件路径。先在 SillyTavern 打开目标角色的单人聊天，再点击“读取额外问候语并自动补全”；插件使用酒馆当前聊天的角色 ID 定位角色卡。弹窗列出开场白编号，就说明角色卡已经定位成功。群聊不会被当作单人角色卡读取。

### 已经列出开场白，但提示没有可识别的 JSON

这说明角色卡已经定位成功，失败的是模型返回格式。0.8.5 起会使用酒馆当前模型、预设与反代执行轻量原始生成，并向支持结构化输出的模型传入 JSON Schema。每条目录固定生成“短标题 / 世界书线路 / 一句话路线简介”：插件会读取当前角色卡内嵌或绑定世界书的具体条目，从“罪人线、少年线”等真实条目名中选择，同一线路可对应多条开场，不再由模型临时编造线路，并自动把线路对应到具体世界书 UID。上游空包或超时时会明确标为待编辑，不再截抄开场正文冒充简介。弹窗底部可选择只补缺失项或全部重新生成；两种操作都不会覆盖已经手写的作品总简介。

### 出现两份状态栏

通常是旧显示正则和新正则同时匹配同一个标签。保留一条显示正则即可；世界书里的输出指导可以保留，但也只保留一份。

### 状态栏模板能不能改成别的用途？

可以。字段名称、填写要求、类型和显示顺序都能修改；生成协议使用稳定记录键，所以可编辑的显示文字不会破坏正则解析。当前数值仍由 AI 随剧情填写，不会写死在插件里。

### 一键安装会不会覆盖别人的正则？

只会更新本插件使用同一规则 ID 或同一名称生成的正则，其他正则不动。安装到当前角色前必须先打开一个单人角色聊天。
