# 状态工坊 · Status Atelier

一个面向 SillyTavern 1.14.0 的前端扩展，用来长期复用同一套状态栏排版，并在设置里快速修改标题、字段文字、布局和颜色。它还会读取角色卡原生的主开场白与备用开场白，让你给每条开场白写简介、快捷切换并跳回聊天第 1 条。

## 它解决什么问题

常见的状态栏美化通常由两部分组成：

1. 世界书要求模型输出 `<status_bar>...</status_bar>` 数据；
2. 正则把这段数据替换成一大段 HTML、CSS 和 JavaScript。

这种做法能显示，但标题、字段和排版都写死在一条很长的正则里。状态工坊把它们拆开：

- 聊天原文只负责保存状态数据；
- 插件设置负责显示标题和字段名称；
- CSS 负责排版和配色；
- 模型输出的状态内容只作为文字显示，不能执行脚本。

插件兼容下面这种通用结构，也兼容参考文件里的 `DateTime / Location / Weather / Affection / Thoughts / InnerThoughts` 组合：

```text
<status_bar>
[DateTime|9月14日 星期六|21:40]
[Location|旧城区 · 临河书店]
[Affection|牵绊|55|+3]
[Thoughts|她刚才那句话，似乎比雨声更难忘。]
</status_bar>
```

## 安装

### 方法一：使用本地 ZIP（最适合第一次安装）

1. 解压 `status-atelier-v0.1.0.zip`。
2. 把解压得到的 `status-atelier` 文件夹放到：

   ```text
   SillyTavern/public/scripts/extensions/third-party/status-atelier
   ```

3. 完全刷新 SillyTavern 页面。
4. 打开顶部“扩展”抽屉，确认能看到“状态工坊 · Status Atelier”。

### 方法二：通过扩展安装器

仓库发布到 GitHub 后，可以在 SillyTavern 的“安装扩展”中粘贴仓库 URL。当前本地交付没有擅自发布到 GitHub，因此暂时请使用方法一。

## 第一次使用

### 1. 先处理旧正则

如果你已经启用了“格子渐变”“水色状态栏”之类的显示正则，请先把这些**显示正则禁用**，不要急着删除。否则旧正则和插件可能同时渲染，出现重复状态栏。

世界书里的“状态栏输出指导”可以继续保留，但同一时间只保留一条匹配的常驻指导。

### 2. 选一个快速预设

打开：

```text
扩展设置 → 状态工坊 · Status Atelier
```

可选：

- `通用信息卡`：日期、位置、天气、好感、内心想法；
- `水色状态栏`：对应水色参考的字段顺序；
- `蓝格票据`：对应格子渐变参考的字段顺序，使用纵向票据排版。

修改主标题、副标题、字段格式或区块标题后，当前聊天会立即重绘。

### 3. 决定由谁要求模型输出状态

- 已经有世界书状态指令：保持“自动向模型注入状态栏格式”为关闭；
- 没有世界书状态指令：打开“自动向模型注入状态栏格式”。

不要同时用两套相互不同的输出规则。字段对不上时，模型容易漏项或重复输出。

### 4. 修改字段文字

“字段格式”每行的写法是：

```text
内部名称|显示标签1|显示标签2|显示标签3
```

例如：

```text
Affection|关系阶段|心动值|本轮变化
```

模型仍然输出 `[Affection|牵绊|55|+3]`，插件显示的标签会变成“关系阶段 / 心动值 / 本轮变化”。

“区块标题”每行的写法是：

```text
Affection=羁绊记录
Thoughts=没有说出口的话
```

### 5. 快速改排版

- `自动网格`：桌面自动分栏，手机自动变为单栏；
- `纵向票据`：每个区块从上到下排列，适合长文字；
- `紧凑横条`：尽量横向排布，适合字段少的状态栏；
- `长文本区`：可让内心想法、日记和书评默认折叠；
- 还可以直接改强调色、底色、文字色、字号、圆角、内边距和最大宽度。

## 开场白导航

插件读取的是角色卡和当前聊天中真实存在的原生开场白 swipe，不会复制一份假开场白。

打开方式有三个：

1. 输入框左侧的扩展菜单中点击“状态 / 开场白工坊”；
2. 扩展设置中点击“开场白管理”；
3. 最新一条状态栏底部点击开场白简介右侧的箭头。

每条开场白可以设置：

- 导航标题，例如“雨夜初遇”“校园线”“重逢线”；
- 简短介绍，例如“你在关门前闯进书店，与他第一次见面”。

标题和简介只保存在插件设置中，不会修改角色卡。点击“切换并定位”时，插件调用 SillyTavern 原生 swipe；点击“只定位到聊天第 1 条”只会滚动页面，不会切换内容。

注意：已经聊了很多轮以后再切换开场白，会改变当前聊天的第 1 条消息，从而改变后续请求看到的历史开端。这是酒馆原生 swipe 的正常行为。

## 导入与导出排版

点击“导出配置”会下载 `status-atelier-profile.json`。这个文件包含状态栏字段、标题、颜色和排版，不包含角色的开场白简介。

在另一台设备上安装插件后，点击“导入配置”选择该文件即可继续使用同一套排版。

## 更新

1. 先在扩展设置中导出配置；
2. 关闭 SillyTavern 页面；
3. 用新版本文件覆盖 `third-party/status-atelier`；
4. 重新打开或强制刷新页面；
5. 如果自定义配置没有保留，再导入之前导出的配置文件。

不要把新版文件叠到错误的双层目录，例如 `status-atelier/status-atelier/index.js`。正确路径中应当直接看到 `manifest.json` 和 `index.js`。

## 常见问题

### 状态栏没有出现

依次检查：

1. 模型回复原文里是否真的包含 `<status_bar>...</status_bar>`；
2. “启用状态栏渲染”是否打开；
3. 字段行是否使用英文竖线 `|`；
4. 点击“读取当前格式”，看插件能否识别当前回复；
5. 浏览器控制台是否出现 `[状态工坊]` 错误。

### 状态栏出现两份

通常是旧显示正则仍然启用。禁用“格子渐变”“水色状态栏”等负责 HTML 替换的正则，只保留世界书输出指导或插件自动注入中的一个。

### 模型有时漏字段

减少互相冲突的状态指令，并检查“字段格式”是否和世界书要求完全一致。可以点击“复制输出指令”，把插件当前生成的规则放进你自己的世界书。

### 好感进度条不动

好感区块需要包含一个 `0–100` 的数字，例如 `55` 或 `55 / 100`。插件不会猜测“很喜欢”具体等于多少。

### 看不到备用开场白

确认当前是单人角色聊天，而且角色卡本身设置了备用开场白。群聊和没有备用开场白的角色只能定位到现有第 1 条消息。

### 更换主题后颜色不协调

状态工坊 CSS 只作用于 `.status-atelier-*` 节点，不会改酒馆全局主题。直接在插件设置里换配色或使用自定义颜色即可。

## 开发与静态检查

无需安装第三方依赖：

```powershell
npm test
```

检查内容包括状态解析、参考字段兼容、清单完整性、危险脚本模式、CSS 作用域、手机端规则、原生 swipe 和原生消息重绘接口。

当前交付的证据级别是“静态检查通过待用户测试”。静态测试不能替代你在实际 SillyTavern / TT 酒馆中的导入截图和点击确认。
