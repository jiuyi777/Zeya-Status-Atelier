# Zeya · 正则状态工坊

面向 SillyTavern 1.14.0 的前端扩展。它不是让用户手动填写“当前好感度、余额、地点和日记”，而是让用户定义这些字段的名称与 AI 填写要求，然后生成：

1. 一份可复制或自动接入当前聊天模型的输出规则；
2. 一份可下载、也可一键安装的 SillyTavern 正则 JSON；
3. 一组按用途设计、字段可编辑而记录键稳定的动态状态界面。

插件还可以生成开场白跳转主页：可自动读取当前角色卡全部开场白并按顺序建立目录，标题、作者、多行推荐模型、多行推荐预设、作品简介、目录条目、字体和整套配色都能修改。每个目录入口还能绑定世界线和具体世界书条目。

仓库内另附四套可直接导入的开场白主页，以及五十套“世界书 + 正则”通用动态状态栏。完整操作见 [新手教程](docs/新手教程.md)。

## 最重要的区别

下面这些是固定定义，由你在插件设置里修改：

- 字段名称，例如“好感度”“信任值”“可用资金”“内心想法”；
- AI 填写要求，例如“填写 0–100 的整数”“第一人称写 50–150 字日记”；
- 切换页名称，例如“角色一 / 角色二”“现实 / 回忆”；
- 状态栏标题、排版和视觉主题；
- 开场白的标题、人物、故事简介和备注。

下面这些不是固定设置，插件中没有输入框，由 AI 每轮根据剧情填写：

- 当前好感数值与本轮变化；
- 当前时间、地点和天气；
- 角色余额；
- 日记正文、内心想法、近期记忆与下一步行动。

## 安装

### 本地安装

1. 解压插件 ZIP。
2. 将 `status-atelier` 文件夹放到：

   ```text
   SillyTavern/public/scripts/extensions/third-party/status-atelier
   ```

3. 确认这个目录下直接能看到 `manifest.json`、`index.js` 和 `settings.html`，不要多套一层同名文件夹。
4. 完全刷新 SillyTavern。
5. 打开“扩展设置”，找到“Zeya · 正则状态工坊”。

### GitHub 安装

在 SillyTavern 的“安装扩展”中粘贴：

```text
https://github.com/jiuyi777/Zeya-Status-Atelier
```

安装后刷新页面，并在“扩展设置”里打开“Zeya · 正则状态工坊”。

## 第一次使用

### 1. 按用途选择模板

内置“攻略关系”“开局信息”“大世界 NPC”“生存数值”四类起始模板。它们只是可编辑的字段组合，不限制角色数量：攻略模板可含好感度和内心独白；大世界模板更适合地点、事件和 NPC；生存模板可显示生命值、体力等数字。

### 2. 修改切换页

每行写法：

```text
按钮名称|这个人物或视角的 AI 要求
```

例如：

```text
喻生|谨慎克制，掌控家族财富，对用户有无法克制的贪恋
喻黎|困在老城区打零工，逐渐陷入无人相信他的困顿
```

这里的描述会写进 AI 输出规则；它不是本轮剧情值。

### 3. 修改字段

每行写法：

```text
显示名称|AI 填写要求|类型
```

例如：

```text
好感度|填写0到100之间的整数，只写数字|progress
本轮变化|填写本轮好感变化，例如+3或-1|number
可用资金|填写具体金额并带货币符号|currency
内心想法|第一人称填写没有说出口的真实想法|long
```

可用类型：

- `text`：普通文字；
- `long`：跨整行显示的长文本；
- `number`：数字或变化值；
- `progress`：0–100 的动态进度条；
- `currency`：金额。

### 4. 让 AI 使用规则

有两种方式，二选一：

- 打开“把生成的规则自动接入当前聊天模型”；
- 点击“复制 AI 输出规则”，放入角色世界书或其他常驻提示位置。

不要同时放入两份不同的状态规则。

### 5. 生成正则

- “下载正则 JSON”：生成一个可以手动导入 SillyTavern 正则扩展的文件；
- “一键安装 / 更新正则”：直接安装到当前角色或全局；再次点击会更新同一条正则，不会无限复制。

生成的正则会捕获整个状态区块，再按当前设置中的字段顺序解析。状态页按钮只切换显示，不会修改 AI 原文。

## AI 实际输出示例

假设使用两个角色页，AI 每轮会生成类似：

```text
<zeya_status>
[Shared|9月14日|21:40|小雨]
[View1|旧城区书店|55|+3|克制|第一位角色的动态想法|动态观察|动态记忆|动态计划]
[View2|老城区修车铺|18|-1|疲惫|第二位角色的动态想法|动态观察|动态记忆|动态计划]
</zeya_status>
```

其中 `View1 / View2` 是稳定记录键；界面按钮显示的是你填写的人物名称。示例数值只用于解释协议，不会保存在插件设置中。

## 开场白主页与导航

插件可以生成四套开场白主页：

- 01 古典对称；
- 03 复古报刊；
- 04 中轴时间线；
- 05 构成编辑。

四张设计方向图存放在 [`docs/previews`](docs/previews)；它们是版式方向图，最终聊天中的文字和条目数量来自你填写的模板。

主页固定资料包括标题、作者、推荐模型、推荐预设和作品简介。推荐模型与推荐预设是多行输入，可以一行填写一个名称。目录由重复的 `[Opening|...]` 记录组成，所以 2 条、8 条、10 条都能自动显示；也可以直接读取当前角色卡全部开场白并按顺序生成。字体以及主页底图、内容卡片、标题文字、推荐信息、简介底色、进入按钮和辅助色均可分别修改，也可一键使用推荐色卡。

世界线定义绑定的是“具体世界书 + 具体条目 UID”，不是整本世界书。进入某条开场白时，主页正则会启用该路线绑定的条目、关闭其他已定义路线的条目，并处理该开场白额外勾选的条目；删除全部世界线后，这部分文字和切换逻辑都会消失。

目录简介可用酒馆当前主 API 与当前预设生成，也可使用自填的 OpenAI 兼容接口，或完全手写。额外接口密钥只保存在本机插件设置中，导出工坊配置时不会带出。

“复制主页模板”用于得到要放进主页开场白的文本；“下载主页正则 JSON”或“一键安装”负责显示和真实跳转。

仓库中的 `starter-packs/开场白主页` 已放好四套成品。每套包含一个正则 JSON 和一个可编辑模板。

### 读取角色卡现有开场白

辅助导航与状态规则分开。

它读取当前角色卡和聊天中真实存在的主开场白及备用开场白。每条开场白可以编辑：

- 导航标题；
- 涉及人物 / 视角；
- 故事简介；
- 备注 / 关键词。

点击“切换并定位”会调用 SillyTavern 原生开场白 swipe，并滚动到聊天第 1 条。已经聊了很多轮以后切换开场白，会改变当前聊天历史的开端，这是酒馆原生行为。

## 更新

1. 先点击“导出工坊配置”；
2. 关闭 SillyTavern 页面；
3. 用新版文件覆盖 `third-party/status-atelier`；
4. 强制刷新页面；
5. 如配置没有保留，使用“导入工坊配置”。

已生成并安装的正则属于 SillyTavern 正则数据，不会因为插件文件更新而自动消失。

## 常见问题

### 为什么设置里没有好感度数字输入框？

因为数字必须由 AI 结合当前剧情填写。设置页只定义“这个字段叫好感度，并要求 AI 填写 0–100 的整数”。

### 为什么预览写着“AI动态填写”？

预览只确认字段数量、切换页和排版，没有冒充当前剧情数据。实际聊天中会显示 AI 回复中的真实值。

### 状态栏没有出现

依次检查：

1. AI 回复原文是否包含设置中的输出标签；
2. 已生成的正则是否启用；
3. AI 输出记录是否保持字段顺序和英文竖线；
4. 是否同时启用了会抢先处理同一标签的旧正则。

### 怎么定位要读取的角色卡？

不需要填写角色卡文件路径。先在 SillyTavern 打开目标角色的单人聊天，再点击“读取额外问候语并自动补全”；插件使用酒馆当前聊天的角色 ID 定位角色卡。弹窗列出开场白编号，就说明角色卡已经定位成功。群聊不会被当作单人角色卡读取。

### 已经列出开场白，但提示没有可识别的 JSON

这说明角色卡已经定位成功，失败的是模型返回格式。0.8.3 起会使用酒馆当前模型、预设与反代执行轻量原始生成，并向支持结构化输出的模型传入 JSON Schema。每条目录固定生成“短标题 / 世界书线路 / 一句话路线简介”：插件会读取当前角色卡内嵌或绑定世界书的具体条目，从“罪人线、少年线”等真实条目名中选择，同一线路可对应多条开场，不再由模型临时编造线路。上游空包或超时时会明确标为待编辑，不再截抄开场正文冒充简介。弹窗底部可选择只补缺失项或覆盖全部重新生成。

### 出现两份状态栏

通常是旧显示正则和新正则同时匹配同一个标签。保留一条显示正则即可；世界书里的输出指导可以保留，但也只保留一份。

### 状态栏模板能不能改成别的用途？

可以。字段名称、填写要求、类型和显示顺序都能修改；生成协议使用稳定记录键，所以可编辑的显示文字不会破坏正则解析。当前数值仍由 AI 随剧情填写，不会写死在插件里。

### 一键安装会不会覆盖别人的正则？

只会更新本插件使用同一规则 ID 或同一名称生成的正则，其他正则不动。安装到当前角色前必须先打开一个单人角色聊天。
