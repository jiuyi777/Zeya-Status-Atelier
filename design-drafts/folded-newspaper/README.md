# 此刻日报 · 折页状态栏样本

作者：九一

折叠封面显示故事时间、地点、人物近况、精神、心情与关系。点击封面或“摊开报纸”显示人物专访、同行关系、物品分类广告。栏目可展开批注，并将选定行动追加到“读者来信”草稿；不会自动发送。提供午后书店、夜间车站两期演示内容，支持本地收藏与减少动态效果设置。

从仓库根目录启动静态服务，例如 `python -m http.server 4205 --bind 127.0.0.1`，访问 `http://127.0.0.1:4205/design-drafts/folded-newspaper/newspaper.html`。人物图片复用相邻 `chibi-characters/assets/character-chibi.png`，请保留这两个目录。

本次提交为独立设计样本，尚未注册到插件模板列表，也未连接 AI 或真实角色卡。插件版本不变。脚本语法、静态资源引用、元素标识及本地资源加载已检查；浏览器自动化连接不可用，折页交互的实际浏览器与 ST/TT 设备验证尚未完成。
