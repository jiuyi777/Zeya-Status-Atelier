# 可视化任务地图正则编辑器

入口：

- `index.html`：八套视觉结构可切换的任务地图编辑器。
- `plugin-preview.html`：从 Status Atelier 当前插件预览进入编辑器。

这不是固定地图截图，也不是共用一套结构的换色模板。编辑器提供八种会改变底图构图、地点对象形态、照片比例、标题形式和路线笔触的地图：

- 木桌案件簿：打开的旧书、证物照片、夹件与红线。
- 旅行地图册：撕边地图、旅行明信片、暖色弯曲路线。
- 城市研究板：白灰建筑图、黑白档案照、黄色便签标题与黑色虚线。
- 黑幕关系网：暗色档案板、胶片证据照、浅色多向关系线。
- 警戒线案件拼贴：黑白撕纸与红线底图，地点可变成黄铜别针拍立得、复古电脑窗口、撕边胶片、报纸证物框或镜头证物照。
- 旅行纪念路线：旧地图、邮戳、格纹包角与旅行红线，五种照片分别以明信片、火车票、行李牌、邮票和折叠地图呈现。
- 城市调查蓝图：蓝灰城市图纸与调查标记，五种照片分别以报纸证物、监控画面、胶片联络表、案件夹和圆形调查镜头呈现。
- 复古数字档案：黑色暗房和旧电脑档案桌面，五种照片分别以文件窗口、CRT、扫描预览、缩略图文件夹和暗房档案袋呈现。

切换地图时只改变视觉模板，不移动地点，也不覆盖名称、图片 URL、介绍、路线、状态或层级。参考图中的地点照片被实现为独立画布对象，每个对象均可：

- 点击选中并用鼠标或手机指针拖动。
- 双击一个起点后，可连续双击任意数量的地点连接红线；重复双击目标撤掉该线，双击起点或按 Esc 结束。
- 键盘方向键仍可作为不显示在界面上的位置调整方式。
- 新增前可选择五种照片款式；名称与外形会随地图模板变化，新地点自动寻找空位，不会一直叠在中央。
- 自行输入地点名称、可选短介绍和 http / https 图片 URL。
- 设定进行中、已走过、可前往、已阻断、未探明状态。
- 地图照片不显示任何状态浮牌；状态数据只用于路线表现和正则输出。
- 调整旋转、大小与层级。
- 从画布工具栏快速复制、删除地点，并支持撤销删除。

八张画布底图均为独立 WebP 素材，不再由 CSS 用一套几何图案模拟。旅行纪念、城市调查和复古数字档案的十五种地点外壳也改为独立透明 WebP，CSS 只负责照片开口、名称位置、缩放和拖动坐标。需要固定物的地点继续直接使用用户提供的黄铜别针、旧棕格绑带与银色票夹抠图。草稿写入浏览器本机存储；旧草稿中的报纸相框会自动降级为五种款式之一。点击“生成正则”会将八张底图、三种附件和十五种地点外壳都转成 data URI 内嵌进可导入 JSON；最终 `replaceString` 是可离线携带素材的 fenced HTML 完整文档，只包含用户选中的成品地图、可选短介绍与返回动作，不包含属性面板、拖动提示、删除按钮、状态浮牌或模板名称工具栏。

素材位置：

- `assets/reference-materials/`：用户提供的三张原始透明素材表，保留原图便于后续换款。
- `assets/attachments/`：从原图无损裁出的编辑器与正则成品附件。
- `assets/map-backgrounds/`：旅行地图册、城市研究板、黑幕关系网、警戒线案件拼贴、旅行纪念路线、城市调查蓝图和复古数字档案的独立空白底图；木桌案件簿底图位于 `assets/` 根目录。
- `assets/place-frames/`：旅行纪念、城市调查和复古数字档案共十五种透明地点外壳。

## 正则输入数据契约

正则匹配：

```text
<quest_map>{JSON}</quest_map>
```

动态 JSON 可包含：

```json
{
  "currentId": "place-2",
  "statuses": {
    "place-1": "completed",
    "place-2": "current",
    "place-3": "available"
  },
  "places": [
    {
      "id": "place-3",
      "name": "AI 更新后的地点名",
      "imageUrl": "https://example.com/place.jpg",
      "intro": "可选的一句地点介绍",
      "frameStyle": "clip",
      "connectFrom": ["place-1", "place-2"]
    }
  ]
}
```

`connectFrom` 兼容旧版单个字符串，也支持地点 ID 数组；数组中的每个地点都会与当前地点各画一条路线，因此一个地点可以连接任意多个地点。正则只负责把已经存在于 `<quest_map>` 中的数据渲染成状态栏，不会写世界书、推进剧情或把玩家点击反向发送给 AI。点击成品地点只打开可选短介绍；不再显示“当前位置”摘要或状态浮牌。旧数据中的 `currentId` 仍兼容为 `current` 状态，但只参与路线数据，不渲染地点文字。动态数据可以覆盖已有地点，也可以追加带坐标的新地点，但不能切换用户选择的地图模板。图片在成品运行时再次限制为 http / https；无法加载时保留照片框，不执行 URL 中的代码。

## 验证边界

- Node 语法、JSON 解析与最终 HTML 外壳属于静态 / 生成物检查。
- 本地浏览器可以验证编辑器的点击、拖动、删除、URL 和返回行为。
- 地图编辑器已从主插件“任务地图”模板入口打开；本目录继续独立维护地图原型代码，不在此处改写主插件生成器。
- 未在 SillyTavern / TauriTavern / TavernHelper 实机中导入前，不能宣称实机通过。
