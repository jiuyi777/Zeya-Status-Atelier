# 地图美化独立原型

入口：`index.html`

这是 `Status Atelier` 的独立地图型状态栏设计稿，只用于收集视觉与交互反馈，不接入主干生成器，不修改现有 `quest` 代码或测试。

## 已覆盖的原型行为

- 4 / 7 / 11 个地点的动态数量变化。
- 地点可点击，打开详情底部面板。
- 浏览器返回键、Esc、面板内“返回地图”都能关闭详情。
- 已走过、当前位置、可前往、已阻断、未探明五类节点或路线状态。
- “模拟 AI 推进一轮”会把第一个可达地点变成当前位置，并同步路线和进度。
- 手机窄屏保持 48px 触控目标；11 地点模式只收起非当前地点的常驻文字，聚焦或点击后仍可读取。
- 当前地点有脉冲反馈，同时有文字、实心节点和状态读出；开启减少动效后不播放脉冲。

## 与当前 quest 契约的对应关系

当前主干的单页 `View1` 六个 AI 值仍可直接映射到原型摘要：

1. `region_weather` → 地图标题区的区域与天气。
2. `objective` → 底部当前任务。
3. `quest_progress` → 任务进度。
4. `next_node` → 可前往节点或当前建议路线。
5. `inventory` → 后续详情中的关键物资（本原型没有替主干新增该 UI）。
6. `risk` → 底部风险提示。

地点数组、坐标和路线状态属于本原型的扩展数据示例。现有主干尚未提供这些结构化字段，不能把本原型的动态地点能力当成已集成能力。

## 验证边界

- HTML/CSS/JS 可以在本地浏览器中独立预览。
- 本原型没有写入或调用 SillyTavern / TavernHelper API。
- 本地浏览器显示与点击不代表 ST/TT iframe、正则生成物或手机实机已通过。
