# Q 版人物状态栏样本

作者：九一

用户确认的 Q 版人物状态栏独立网页样本。三位示例人物支持点击心声气泡和轻弹动画、左右滑动、箭头、头像与键盘切换。状态默认展开；玩家可以为每位人物独立上传图片或恢复样板，图片通过 IndexedDB 保存在当前浏览器，存储不可用时明确提示仅本次有效。

在本目录启动静态 HTTP 服务（例如 `python -m http.server 4205 --bind 127.0.0.1`），然后访问 `http://127.0.0.1:4205/characters.html`。使用固定地址和端口才能读取同一浏览器存储。上传图片不会发送到服务器。

此目录是样本，不注册插件模板；人物、心声和状态均为演示数据，尚未连接 AI 或真实角色卡。插件版本不变。已完成脚本语法、资源引用与图片尺寸检查，用户已确认 Q 版视觉方向；真实 ST/TT 集成及设备运行尚未验证。

## 样板图片

`assets/character-chibi.png` 使用内置 imagegen 生成。参考用户提供图片的 Q 版视觉方向，绘制原创三位示例人物，未打包用户参考图片。

生成要求：三等分正方形单元的横向图集；大头短身、精致手绘描线、柔和配色、丰富配饰。棕发绿开衫笔记本女孩、黑蓝发旅行外套男孩、金发紫贝雷帽花束女孩。最终背景统一为奶油色，无棋盘格、外发光或投影。
