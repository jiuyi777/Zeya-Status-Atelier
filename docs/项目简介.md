# 九一 · 正则状态工坊功能简介

## 一句话介绍

九一 · 正则状态工坊是一款面向 SillyTavern 的移动端友好扩展；展开扩展后会进入“酒馆美化工坊”操作界面，用来制作可点击的开场白主页，以及由 AI 随剧情自动填写的动态状态栏。

它输出的是能够真正导入和运行的 HTML、CSS、正则 JSON 与世界书 JSON，不是只能观看的设计图。

## 主要功能

### 通用开场白主页

- 读取当前角色卡真实存在的额外问候语；
- 自动建立开场白目录；
- 编辑主页标题、小副标题、作者、推荐模型、推荐预设和作品简介；
- 自定义字体、整套色卡和单项颜色；
- 从世界书条目中识别罪人线、少年线等真实线路；
- 将目录绑定到额外问候语和可切换的世界书 UID；
- 玩家点击“进入”后，跳转到对应开场白并按需切换线路条目。

### 动态状态栏

- 9 种可编辑组件结构：人物名片、种草动态、论坛、聊天、拼贴、音乐、任务、案件和自由组件；
- 20 套人物状态栏成品；
- 12 套可独立组合的色卡；
- 可修改字段名称、字段类型、AI 填写要求、顺序和排版；
- 支持当前角色头像、当前 User 头像、图片 URL、封面图和音乐 URL；
- 音乐由玩家手动播放，不会自动播放；
- 可以下载世界书与正则，也可以直接应用到当前角色或全局。

### AI 生成与检查

状态栏不是让用户每天手工修改好感度、地点、余额或任务进度。用户只需要规定字段和填写要求，AI 会在每轮回复中根据剧情生成真实值，正则再把这些值显示成界面。

“测试当前 AI 生成”会使用酒馆当前模型、Key、API 地址和预设发出一次真实请求，并检查返回内容是否完整。API Key 不会写入导出的正则、世界书或工坊备份。

## 适合谁

- 想为角色卡制作作品导航页的作者；
- 有多条额外问候语或多条世界线的角色卡作者；
- 想做人物关系、论坛、聊天、任务、案件、音乐或社交动态状态栏的用户；
- 不会手写复杂 HTML、CSS 和正则，但希望继续编辑成品的人；
- 主要使用手机、TauriTavern 或窄屏界面的玩家。

## 使用边界

- 插件不会凭空新增角色卡原本不存在的额外问候语；
- 不会把角色图片或音乐上传到网络；外链资源需要设备本身能够访问；
- 预览中的文字是排版示例，不是角色的真实剧情值；
- 本地测试通过不等于所有 SillyTavern 主题、TavernHelper 版本和手机设备都已经验收；首次使用仍建议先在测试角色中检查完整流程。

完整安装与操作步骤见 [新手教程](新手教程.md)。
