# 四时小物 · 四款开场白

交付版本 0.11.39，手机更新与下载见[更新说明](开场白手机更新说明.md)。四款共用编辑、图片插入和问候语切换能力，各自保留独立的构图与开场动作。

| 模板 | 首屏与打开方式 | 展开后的布局 | 默认字体 |
| --- | --- | --- | --- |
| 风藏书页 | 雾蓝布面小书，点击翻开封面 | 宽屏双页目录，手机纵向书页 | 宋体 |
| 留声片刻 | 米白墨绿磁带，点击后带轮转动 | 带 A 面标识的曲目单 | 黑体，磁带标签使用楷体 |
| 沿途拾光 | 带折痕的小地图，点击展开两侧 | 编号地点与虚线路径 | 仿宋 |
| 一页晴天 | 纸夹、透纸、彩铅小花，点击揭开描图纸 | 浅色纸张与手稿式目录 | 楷体 |

所有开场动作只需点击一次。进入正文后，在正文末尾返回目录；同一次阅读返回后保持展开。重新载入页面时恢复小物件首屏。支持系统的减少动态效果设置。

## 预览和编辑

运行 `node scripts/serve-opening-library.mjs`，访问：

`http://127.0.0.1:4204/opening-keepsake-preview.html`

顶部四个标签切换样式，各自保留本次编辑内容；“保存本地草稿”按模板分别保存，下次打开会恢复。作品名可通过“修改名称”或展开后点击标题修改。“重看开场”是编辑预览工具，不会写入角色卡。

“展开编辑”里可修改简介、正文、条目顺序、字体、字号和颜色。可选配图留空时不保留图片框；简介和正文可在光标处插入多张图片。选图、压缩和图床上传共用工坊现有功能。

## 接入工坊与导出

四款都进入工坊外观列表和模板展架，展架提供可编辑预览入口。已有角色卡可选择新外观后重新生成主页；真实开场白序号与世界书绑定仍由工坊原有导航执行。

预览可下载：可编辑配置、开场白字段包、工坊外观模板。外观模板仅携带样式，导入后保留原作品内容与绑定。字段包包含示例 `first_mes` 与 `alternate_greetings`，不是完整角色卡。

运行 `node scripts/build-keepsake-packs.mjs` 可重建四款的 12 份 JSON 到 `output/四时小物/`，每款包括开场白字段包、主页与返回正则、外观模板。构建时检查文档闭合、脚本语法、JSON 读回以及图片外链。

## 素材与体积

布封、磁带与地图均为可伸缩的 HTML/CSS 元素，文字保持可编辑。纸张与布纹通过样式形成。

描图纸的彩铅小花由内置 imagegen 生成，保留透明背景，压缩为 560 × 560 WebP、46,066 字节。源文件为 `assets/opening-keepsakes/pencil-chamomile.webp`；导出只写 HTTPS 外链。图片按既有授权发布在仓库 `opening-keepsake-artwork` 素材分支，模板代码与下载包随 v0.11.39 一并发布。

## 验证边界

本轮检查模板生成、随卡返回规则、真实序号与世界书绑定的测试接口；本地浏览器检查四款开场、阅读返回、手机宽度与编辑保存导出。真实 SillyTavern / TauriTavern 和用户图床上传仍需目标环境验收。

设计参考路由：`sillytavern-component-update`；库快照 `2026-08-18`，采用 A0 的目标、修改边界与验收划分，沿用现有组件的完整 HTML 和导航契约。四种视觉为本轮原创备选，未采用外部模板。
