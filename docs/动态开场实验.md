## 使用

- 动态总览：`http://127.0.0.1:4204/opening-kinetic-overview.html`
- 编辑与下载：`http://127.0.0.1:4204/opening-kinetic-preview.html?theme=soft-clock`
- 另两款 theme 参数为 `signal-field`、`pixel-dusk`。
- 点击作品标题改名，点击标题下的“作品介绍”和当前故事的“本篇简介”直接修改；顶部也提供“编辑作品介绍”和“保存草稿”。完整编辑区支持字体、简介、条目顺序、正文、可选图片。正文插图使用现有压缩与图床工具。
- 介绍不再作为小字页脚显示；多段文字保留换行，长文自然增高。未填写的介绍在编辑预览里显示填写提示，导出不带编辑操作。
- 顶部像素大字可以直接点击编辑，完整面板也有独立字段。支持 A–Z、数字、标点、换行，中文与其他字符使用本地字体显示；最多 80 字，留空隐藏。草稿、可编辑配置、字段包、工坊生成都保留此字段；外观模板不覆盖用户文字。
- 旧像素草稿只有精确匹配两代工厂默认的荧光黄 / 旧纸金、原默认文字色才迁移；自定义颜色、介绍、正文、图片和条目 ID 保留。
- 用户明确禁止“左侧强调色条 + 同色系填充底块”。已写入 `C:/sta/AGENTS.md`，去掉动态页介绍区的侧条，并清理共用生成器、旧玻璃 / 拼贴模板与小物介绍中的同类做法。保留钟面等器物的必要轮廓和纯分隔线。
- 当前按钮打开已填写的正文，不会调用 AI。默认附带六段短示例，需替换为角色卡内容。
- 暂停与选篇状态在当前访问内保留。回到导航从原篇目继续；时钟会继续转动，收音机保持选择；像素小车从原篇停靠后继续巡游。刷新开启新的访问。草稿通过“保存草稿”单独持久化。
- 导出目录：`output/动态开场实验/`。每款提供开场白字段包、主页与返回正则、工坊外观模板。
- 字段包包含示例正文；工坊外观模板只替换样式，保留既有正文、真实序号和世界书线路。不要以示例包覆盖未备份的角色卡。

## 动态与交互合同

- 页面负责图形与运动，无视频依赖。时钟与扬声器为 SVG；收音机音柱由 CSS 控制。《下一站》大字每隔 190ms 出现一个字符，只显示一遍，完成后保留全文，不循环晃动或擦除。暂停或减少动态时直接显示完整文字。
- 时钟用同一角度计算红色指针和当前篇号；指针与篇目按最近刻度同步。按下鼠标、触摸或键盘确认时短暂冻结，再执行原跳转；未跳转时 1.2 秒内恢复，不保存为永久暂停。
- 根据用户继续转动的最新要求，点编号只调整指针位置，自动轮选继续。只有“暂停指针”会保存为手动暂停；再次点击可恢复。旧版点选留下的自动暂停不会延续。
- 收音机频段、LCD 数值、调频滑条、旋钮位置、预设按钮与正文一起更新；动画音柱不改变选择。这是故事选择器，没有真实音频或广播接口。
- 铁路与小车共用路径几何。点击站点，小车由当前位置沿轨道移动，到站才更新篇号、简介与阅读目标；连续点击会改道。每站默认停留 4.6 秒，手动选站后停留 9 秒，末站后倒行返回。手机按两列折返过弯，中等宽度按篇数均衡分行，宽屏最多六站一行。标题很长时增加行距。
- 收音机音柱不改变选择；像素小车巡游会选中停靠篇目。阅读时不播放背景动画，返回从原篇停靠恢复。暂停或减少动态时，点站直接抵达并可正常阅读。
- 页面离屏或标签隐藏时暂停。时钟逐帧推进；小车只在行驶时逐帧更新，停站期间使用计时器，轨道离屏时也暂停。收音机没有空转的帧循环。离开时清理计时器、帧请求、事件与观察器。
- 系统减少动态偏好默认停止动画；手动编号仍可选择和阅读。所有滚动区域隐藏滚动条外观，保留滚动。
