# 手机更新开场白 · v0.11.39

[本版下载页](https://github.com/jiuyi777/Zeya-Status-Atelier/releases/tag/v0.11.39)

## 更新工坊

在酒馆的扩展管理中找到“九一 · 正则状态工坊”，点击更新，完成后刷新酒馆。版本应显示 **0.11.39**。

本版包含全部累计开场白修改：时钟、像素收音机、中央铁路小车、花信与其他旧款排版、四时小物、正文底部返回和顶部空白修复。已经导出的旧卡不会自动改变，请重新生成并应用主页与返回正则；正文和世界书绑定沿用原卡。

## 只修复已有卡片上方的空白

1. 下载 [opening-return-fix-v0.11.39.json](https://github.com/jiuyi777/Zeya-Status-Atelier/releases/download/v0.11.39/opening-return-fix-v0.11.39.json) 到手机。
2. 打开对应角色卡，进入扩展 → 正则，停用旧的“九一 · 开场白返回作品目录”。如果全局和局部都装过这条规则，两处都检查。
3. 导入刚下载的文件，选择“局部正则脚本”，并启用角色局部正则。
4. 刷新酒馆并重新进入这段聊天。分享角色卡时重新导出，才会带上新规则。

**手工导入会新增规则，不会自动覆盖旧规则；第 2 步不能省略。** 无需改写开场白正文或替换整张角色卡。HTML 开场白继续需要酒馆助手的前端渲染功能。
