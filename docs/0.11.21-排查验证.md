# 0.11.21 排查验证

基线：发布工作区 portable-release-01117，0.11.20 / 3617e03；开始时工作区干净，远端 main 与本地一致。原角色卡和其他工作区保持原样。

## 已复现与修复

1. AI 选择另一人物模板时，applyStatusStructure 先写入默认标题和字段，随后 applyProfileAppearance 保存的旧草稿已经是默认值。使用实际函数复现，自定义标题变为“绛幕雪信”，自定义字段消失。现在先保存原草稿，再直接选择目标外观并应用结构；调用方继续使用生成前取得的候选内容恢复目标字段。
2. 错误文本为“502 Bad Gateway: upstream returned 429 Too Many Requests”时，原提示只解释 502。现在显示网关 502 和上游 429 限流；只收到 502 时仍按已知的 502 信息解释。
