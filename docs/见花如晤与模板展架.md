# 见花如晤与模板展架

本页对应 v0.11.36。花信主页、可调整预览和工坊生成内容共用同一个生成器。

## 使用花信主页

1. 更新正则状态工坊并刷新页面，在开场白主页外观中选择“见花如晤”。
2. 填写作品名称、简介和实际开场白，按需添加世界书绑定。
3. 重新生成并应用主页；旧的已导出正则需要重新生成。

首屏显示青绿花绳信封，点击一次就连续展开整张信纸与目录。阅读开场白后返回目录保持展开；重新打开或刷新预览时先显示信封。没有再次拆信步骤或合上按钮。

默认字体为轻楷体，仍可切换其他字体。展开后的作品名是右上方小落款，预览中可点击修改。信纸按内容自然增高；滚动条隐藏外观，滚轮、触摸和键盘滚动仍可使用。

已读状态只对当前宿主页面的这次加载有效；同次阅读重新挂载目录时恢复展开。草稿正文和角色卡数据不受这一临时状态影响。

## 图片与压缩

定稿信封由 imagegen 生成，发布文件为 `assets/opening-bloom-letter/letter-turquoise-cord.webp`，960 × 720、111,968 字节，保留透明通道。

默认导出使用以下在线链接，位图不会内嵌到角色卡：

https://raw.githubusercontent.com/jiuyi777/Zeya-Status-Atelier/main/assets/opening-bloom-letter/letter-turquoise-cord.webp

信封链接留空时使用定稿插画。更换插画时可提供自己的 HTTPS 图床链接。自己的作品配图可留空，没有配图时不会留下空框。

工坊简介和花信预览的简介、正文支持在光标处插入图片；同一段内容可插入多张 Markdown 图片，图片标记可随文字剪切移动。

1. 在目标位置点击插图，选择文件、粘贴或拖入图片。
2. 选择最长边 1200、800 或 480px，自动压缩为约 220KB 内的图片，保留透明背景。
3. 配置 Cloudinary unsigned preset 或 ImgBB API Key，上传压缩图；已有 HTTPS 图片链接也可直接插入。

上传失败时可下载压缩图片，不会把原始大图写入内容。API Key 只留在当前窗口，不写入本机草稿、角色卡或导出文件。默认插画无需另配图床；自行上传到第三方图床的实际账号链路尚未验收。

## 模板展架与分享

工坊提供“模板展架 / 投稿”“下载外观模板”和“导入外观模板”。外观包只包含排版、字体和配色，不包含用户正文、世界书资料或开场白绑定；导入时保留这些原有内容。

- 内置模板可直接下载。
- 导入到“本机展架”只保存在当前浏览器。
- 投稿入口打开本仓库的 GitHub Issue 草稿，由投稿人登录、附上外观 JSON 和截图后提交。审核合入后才进入公共模板列表。

这里没有独立账号服务器；本机收藏不会自动变成公开投稿。

## 本地预览与验证范围

在仓库根目录运行：

```sh
node scripts/serve-opening-library.mjs
```

打开 `http://127.0.0.1:4204/`。编辑栏默认收起，展开后可编辑、保存本机草稿或导入、导出配置。字段包包含 `first_mes` 与 `alternate_greetings`，不是完整角色卡。

本地浏览器已验证信封首屏、一次点击展信、阅读返回保持展开、刷新恢复信封、字体切换以及手机宽度。相关检查覆盖导出文档、默认图片外链、临时状态和模板导入时的数据保留。

工坊同时保留 v0.11.35 的随卡返回导航。真实 SillyTavern / TauriTavern 运行及第三方图床上传仍需目标环境验收，本地浏览器与自动化检查不能替代它们。
