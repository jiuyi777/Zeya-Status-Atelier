# 1.0.3 · 手机预览与制作界面

- 扩展抽屉提供「制作状态栏」「制作开场白主页」两个入口，完整工坊可展开。
- 状态栏设置按「模板 / 内容 / 外观」分区；模板支持编号、名称和简介搜索。
- 手机预览默认最多占屏幕高度的 20%，上限 176px。支持放大查看、返回编辑和收起，切换保留正在填写的内容与同一个预览画面。
- 点击放大预览中的可编辑字段、文字或头像时，自动返回编辑区。
- 修复标签栏吸顶时上方留下空隙，导致字段说明从预览下沿漏出的问题；手机和电脑共用布局均已修正。
- 手动调整时安装按钮固定在底部；开场白制作界面依次展示外观预览和作品资料。

## 更新方式

在酒馆扩展管理中更新「九一 · 正则状态工坊」，刷新页面后重新打开制作器。这次更新编辑界面，已有角色卡和正则内容保持原样。
