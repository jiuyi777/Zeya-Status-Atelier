# 0.11.19 运行验证

2026-09-10，独立数据目录、SillyTavern 1.14.0、酒馆助手 4.9.5，浏览器真实聊天消息渲染。没有调用模型 API。

## 已复现与修复

- 角色头像 PNG 内的文字块包含完整卡片，随正则重复导出形成嵌套。导出器现只嵌入图像数据，同时清理已有 data URL 中的 PNG 文字块。
- 用户样本由 38,073,546 字节降到 14,034,370 字节。PNG 图像块及正则以外的卡片字段逐项比对一致，最终 PNG 块校验通过。卡片样本保留在本机，不随仓库发布。
- P08、P09 的窄屏展开高度覆盖了收起高度；隐藏内容的滚动高度又被用于 iframe 测量。现按展开状态应用自动高度，收起时使用可见卡片高度。
- 窗口改变宽度后使用当前卡片宽度重新计算缩放，避免已重排的手机布局被再次缩小。

## 真实运行结果

- 使用中性的 P08 八字段、P09 十三字段状态消息，原卡与修复卡均能触发各自正则并显示美化。
- 在扩展管理中停用 `third-party/status-atelier`，刷新后重新打开聊天，确认工坊未加载；修复卡两套状态栏仍显示，头像和背景加载成功。
- P08 收起状态的实际 iframe 高度为 116 像素；修复前同一窄屏场景约为 874 像素。
- P09 实际点击下一张切换到身体页；收起后 iframe 高度为 116 像素。
- 152 项自动检查通过，静态检查通过。
