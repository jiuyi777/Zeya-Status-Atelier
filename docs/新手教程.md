# Zeya · 正则状态工坊新手教程

这套工具分成两件互不冲突的功能：

1. **开场白主页**：放在角色卡的某一条开场白里，显示作品资料和目录，点击目录会切换到真实的备用开场白。
2. **动态状态栏**：世界书告诉 AI 每轮该输出哪些状态，正则负责把 AI 输出变成好看的可切换界面。

不要把状态栏里的“好感度、余额、地点、想法”等当前值写进插件设置。你只修改字段名称和填写要求，真实值由 AI 跟随剧情生成。

## 一、安装插件

1. 下载发布页中的 `status-atelier-v0.4.0.zip`，或在酒馆“安装扩展”中粘贴 `https://github.com/jiuyi777/Zeya-Status-Atelier`。
2. 解压后确认文件夹中直接能看到 `manifest.json`。
3. 把整个 `status-atelier` 文件夹放到：

   ```text
   SillyTavern/public/scripts/extensions/third-party/status-atelier
   ```

4. 完全刷新 SillyTavern。
5. 打开“扩展设置”，找到“Zeya · 正则状态工坊”。

不安装插件也可以直接使用仓库 `starter-packs` 文件夹中的成品 JSON。

## 二、制作开场白跳转主页

### 方法 A：使用插件编辑（推荐）

1. 在插件中找到“开场白主页正则”。
2. 填写主页标题、作者、推荐模型、推荐预设和整部作品简介。
3. 从四套风格中选择一套：
   - 01 古典对称；
   - 03 复古报刊；
   - 04 中轴时间线；
   - 05 极简留白。
4. 推荐模型和推荐预设可以换行，一行填写一个名称。
5. 使用推荐色卡，或分别修改主页底图、内容卡片、标题文字、推荐信息、简介底色、进入按钮和辅助色；右侧/下方预览会同步变化。
6. 如需路线切换，先新增世界线，再为它选择一个或多个“具体世界书条目”。全部删除则主页不显示任何世界线内容。
7. 点击“读取当前角色卡全部开场白并生成目录”。插件会按真实顺序创建入口；也可手动新增或删除。
8. 每条只需编辑标题、人物和简介，选择已经定义好的世界线；需要时可额外勾选其他条目。
9. 点击“复制主页模板”，把模板全文放入角色卡的主页开场白。
10. 点击“保存并应用到当前角色卡”或“保存并应用到全局”，也可下载主页正则 JSON 后手动导入。

### 跳转顺序

使用“读取当前角色卡全部开场白”后，跳转序号由真实开场白顺序自动生成，不需要逐条手填。手动新建目录时，插件也会按条目顺序生成目标位置。

### 可编辑模板格式

```text
<opening_home>
[Meta|作品导航|STORY HOME|Zeya|推荐模型|推荐预设]
[Style|classical|serif|#a85f5b|#fffaf1|#443c38|#6d9799|#fffdf8|#f5ede1|#17324d]
[Intro|这里填写整部作品简介。]
[Worldline|line-1|雨夜线|JSON编码后的世界书条目]
[Opening|01|雨夜初遇|角色A · 角色B|第一次相遇的故事线。|2|line-1|额外条目]
[Opening|02|旧城重逢|角色A · 角色B|多年后重逢的故事线。|3||]
</opening_home>
```

每增加一行 `[Opening|...]` 就增加一个目录入口；删除这一整行就删除一个入口。不要在字段里直接使用英文竖线 `|`。

## 三、安装通用动态状态栏

### 最简单的成品用法

进入 `starter-packs/通用状态栏`，从 01 到 50 选择一套。每套文件夹里有：

- `世界书-....json`：导入世界书；
- `regex-....json`：导入正则；
- `世界书正文-....txt`：用于查看或手动复制规则。

世界书和正则必须选择同一编号。世界书负责让 AI 输出动态数据，正则负责显示。

01–20 是基础人物状态风格；21–50 是用途和视觉结构都不同的迷你网页风格，包括贴纸种草、弹幕放映、复古论坛、直播、群聊、水墨日记、唱片播放器、千禧播客、达达拼贴、洛可可杂志、包豪斯商品、孟菲斯食评、旅行护照、瑞士列车、天气、任务手抄本、黑色电影案件、塔罗、赛博、生存、医疗、论文、仪表盘、拍卖、体育、报纸、标本、咖啡收据、电影票根和关系纪念册。

在插件里切换外观不会替换人物、剧情或动态字段；标题、字段名称、字段类型、填写要求和排版仍可继续编辑。

### 用插件修改字段

1. 按用途选择“攻略关系”“开局信息”“大世界 NPC”或“生存数值”。
2. 在“切换页”中每行写一个人物或视角：

   ```text
   角色一|填写第一个人物的姓名、身份和状态要求
   角色二|填写第二个人物的姓名、身份和状态要求
   ```

3. 想增加第三页，继续加一行；想删除某页，删掉对应整行。
4. 在字段中使用：

   ```text
   显示名称|AI 填写要求|类型
   ```

5. 可用类型：`text`、`long`、`number`、`progress`、`currency`。
6. 点击“下载世界书 JSON”。
7. 点击“下载正则 JSON”，或直接“生成并应用到当前角色卡 / 全局”。
8. 在 SillyTavern 中导入并启用刚才生成的世界书。

例如“好感度”应该写成：

```text
好感度|根据当前剧情填写0到100之间的整数，只写数字|progress
```

这里没有填写具体的 `55`。AI 每轮会根据剧情产生不同数字，正则再把数字显示为进度条。

## 四、导入位置

### 导入世界书

1. 打开顶部“世界书 / World Info”。
2. 点击导入。
3. 选择 `世界书-....json`。
4. 把它关联到当前角色，或作为当前聊天世界书启用。

### 导入正则

1. 打开“扩展”中的正则设置。
2. 导入 `regex-....json`。
3. 确认正则已启用，并选择当前角色或全局范围。

如果使用插件的一键安装，先打开一个单人角色聊天，再选择“当前角色”。

## 五、常见问题

### 为什么主页有 8 条，但只显示 3 条

确认 8 条都写在同一个标签区块中，而且每条都以 `[Opening|` 开头并以 `]` 结束。

### 点击“进入”没有反应

确认角色卡确实有对应数量的备用开场白，并检查该条目的跳转编号。跳转使用 SillyTavern 原生 swipe，不能跳到不存在的序号。

### 状态栏每次内容都一样

通常是把示例值写死进世界书了。重新使用插件生成世界书，或使用成品包里的世界书。模板双花括号表示 AI 填写要求，不是固定答案。

### 出现两份状态栏或两份主页

同时启用了两条匹配同一标签的正则。保留正在使用的一套即可。五十套状态栏成品使用独立标签，可以同时导入，但一个角色通常只启用当前需要的一套世界书与正则。

## 六、验证边界

仓库中的自动测试会检查 JSON 结构、动态条目数量、世界书格式、正则脚本语法、手机端 CSS 和原生 swipe 调用。额外 OpenAI 兼容 API 没有在仓库中保存密钥，也不做联网实测。不同酒馆主题、浏览器和角色卡仍可能影响最终视觉，因此第一次导入后请在自己的 SillyTavern 中查看桌面与手机效果。
