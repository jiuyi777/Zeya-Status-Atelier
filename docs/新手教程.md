# 九一 · 正则状态工坊新手教程

这个插件可以制作：

- **开场白主页**：把角色卡的额外问候语变成可点击目录。
- **动态状态栏**：让 AI 随剧情填写人物、论坛、聊天、拼贴、音乐等界面。

生成的是可编辑、可导入酒馆的 HTML、CSS、正则和世界书，不是图片。

## 安装

在 SillyTavern 打开“扩展 → 安装扩展”，粘贴：

```text
https://github.com/jiuyi777/Zeya-Status-Atelier
```

安装后刷新页面，在扩展设置中打开“九一 · 正则状态工坊”。使用前先进入目标角色的单人聊天。

## 制作开场白主页

1. 在魔棒菜单点击“制作开场白主页 / 状态栏 · 九一”。
2. 可点击“一键生成并复制开场白一览”；摘录保持角色卡原文。
3. 检查作品简介、线路和目录，点击“一键生成并应用”。

世界线和 UID 可以不设置；不设置时仍能正常跳转额外问候语。

## 制作动态状态栏

在同一个魔棒弹窗选择 50 套外观之一，点击“直接启用 / 覆盖当前角色状态栏”。需要改字段、头像、图片或音乐时再进入完整工坊。

手动安装时，必须同时导入**世界书 JSON**和**正则 JSON**。

## 出错怎么办

- **显示代码块**：重新生成并启用最新版正则，确认 TavernHelper 能渲染 HTML。
- **状态栏不显示**：检查 AI 回复末尾有没有 `<zeya_status>`；有标签再检查正则，没有标签就检查世界书和模型。
- **404、502、524 或超时**：先用相同模型在普通聊天中测试，再检查 API 地址、模型名和上游接口。

> 更新插件前请先备份编辑配置。自动测试通过不等于手机端实际验收通过。
