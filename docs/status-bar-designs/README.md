# 30 套通用状态栏设计

这批设计把状态栏当作一个可折叠、可分页、由世界书动态数据驱动的移动端迷你网页，而不是固定人物的装饰卡片。

## 设计板

- A｜社交与社区：01 种草笔记、02 弹幕视频社区、03 论坛主题帖、04 直播间、05 即时群聊
- B｜私人与内容：06 私人日记、07 音乐播放器、08 播客节目、09 摄影拼贴、10 电子杂志
- C｜生活与服务：11 商品详情、12 美食评价、13 旅行护照、14 列车时刻、15 天气观测
- D｜叙事与游戏：16 RPG任务日志、17 侦探案件档案、18 塔罗占卜、19 赛博终端、20 生存监控
- E｜专业与机构：21 医疗档案、22 学术论文、23 企业仪表盘、24 拍卖行、25 体育赛况
- F｜纸媒与纪念：26 复古报纸、27 植物标本、28 咖啡收据、29 电影票根、30 关系纪念册

## 实现边界

1. 图片中的人物名、标题和数值只用于说明布局，不能写进正则或世界书。
2. catalog.json 的字段是通用语义；实现时仍需为每个字段生成稳定 key。
3. 世界书只约束 AI 输出，正则只解析完整标签块，HTML 只渲染当前动态值。
4. 每套必须支持 390px 手机宽度、触控、折叠、长文本换行和无数据占位。
5. 借鉴社交、视频、论坛等产品的信息结构，不使用第三方官方 Logo、品牌名或受保护素材。

## 下一阶段

按 catalog.json 生成 30 个外观预设，并为结构差异较大的设计提供独立 renderer；不能只给同一 DOM 换 30 组颜色。
