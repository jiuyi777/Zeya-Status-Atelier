# 开场白随卡返回修复

## v0.11.39：酒馆顶部空框

在独立 SillyTavern 1.14.0 中通过角色卡导入复现：旧返回规则在主页前生成一个按钮已隐藏、body.scrollHeight 为 0 的 iframe，酒馆助手仍保留 iframe 默认的 150px 高度。规则按顺序执行，主页已先替换成 HTML，因此返回规则仅排除原始【主页】标记也无法避免这个空框。

共用生成器现在为主页加入标记，返回规则排除已生成的主页。返回运行时在不适用的主页、无目录卡和后续楼层中折叠它自己所属的 iframe；需要显示按钮或错误说明时恢复高度。只操作自己的框，不调整酒馆主题、其他消息或正文排版。

实际旧卡修补路径已验证：停用旧返回规则 → 将 output/opening-host-gap/开场白-返回与顶部空白修复.json 导入局部正则 → 刷新并重开聊天。原来的顶部空框消失；主页起点从 228px 回到 72px，空返回框高度为 0；进入正文后返回框位于正文之后，高度 52px；点击返回后再次归零。SillyTavern 的手工导入会分配新 ID 并追加，所以必须先停用旧规则，不能把再次导入当作覆盖。工坊自己的应用流程仍按固定 ID 更新。

295 项自动检查及 STATIC_CHECK_OK 通过。新增检查在修改前复现两项失败：规则顺序导致主页多余框、隐藏按钮未折叠 iframe。三款动态包、四款小物包、通用入门包与当前 ZIP 已重建。实际浏览器证据、日志和修补文件位于 output/opening-host-gap/。测试环境是独立本机酒馆；用户手机客户端尚未核对。源码、入门包和单条修补文件随 v0.11.39 发布。手机操作与远程下载见[更新说明](开场白手机更新说明.md)。

## v0.11.39：返回放在正文末尾

旧返回正则匹配消息起点，所以把独立返回 iframe 插在正文前；独立阅读模板同时在页首、页尾生成返回按钮，预览工具栏也有重复入口。现在随卡规则用单个全文捕获保留原文，并在末尾追加完整 HTML 代码块；阅读模板只在正文、配图之后提供返回，花信放在落款之后。规则 ID 保持不变，工坊应用时可覆盖旧规则；手工导入时应先停用旧规则。已导出的旧角色卡需要重新生成、应用主页与返回规则；旧字段包需要重新导出。

本机 SillyTavern 的 regex/engine.js 使用数字捕获展开替换内容，因此采用 `$1`，而非原生 String.replace 的 `$&`。长文、换行、已有 HTML 代码块与正文中的美元符号均由回归检查覆盖。

一并修正花信的页面定位：只读取 main/header 元素上的页面标记，脚本中用于查询主页的文字不会再被当成第二个主页。返回仍读取当前 swipes，只修改实际主页的 swipe_id。

本轮验证：293 项自动检查与静态检查通过；12 份生成规则用本机 regex/engine.js 的替换函数在隔离环境执行，宏展开保持为透传。浏览器检查了《下一站，像素》手机宽度下的末尾入口、点击返回与原篇目恢复；截图位于 output/opening-return-revision。

## v0.11.35 已发布记录

根因：返回按钮仅由工坊扩展初始化时挂到聊天 DOM，主页 iframe 被替换后，卡内没有独立的返回实现。制作端安装工坊掩盖了接收端缺失。

修改：下载 JSON、局部/全局安装、四套入门包均输出主页与返回两条规则。返回规则是随卡的完整消息 iframe，读取当前第 0 楼的实际 swipes，找到唯一【主页】后只切换 swipe_id，保留所有正文。入口在消息重新渲染时恢复，不依赖先访问主页、父窗口常驻回调或远程加载工坊。安装时保留两条独立 ID，并沿用写入后的持久化回读与正则引擎确认。旧卡仍保留工坊返回兜底，安装了启用的配套规则时关闭旧兜底，避免重复。

接收端需要启用角色局部正则和酒馆助手 HTML 前端渲染，不需要正则状态工坊。配套正则为仅显示的 AI 消息规则；仅第 0 楼且存在唯一主页的非主页页显示按钮，后续楼层不读取或改写消息。旧卡可只导入交付的返回规则，再导出角色卡分享。全局安装不会随角色卡导出，分享应选择局部安装。

来源核对：本机 SillyTavern 1.14.0 的 regex/index.js 接受规则数组；本机酒馆助手 4.9.3 的 @types/iframe/util.d.ts 与 @types/function/chat_message.d.ts 声明 getCurrentMessageId、getChatMessages(include_swipes) 及 setChatMessages(swipe_id, refresh:affected)。这属于源码/声明核对，未检测接收者实际版本。

验证：234 项测试及静态检查通过。实际执行序列化导出代码的 VM 未注入工坊、父窗口或工坊设置；覆盖返回、模拟重新打开、重排页、主页缺失/重复、后续楼层、保存失败重试。安装模拟覆盖持久化回读、重复安装、旧规则保留和两条独立 ID。四套交付 JSON 已重新生成。没有运行中的真实 ST/TT 客户端，本次未完成真实导入、持久化重开或手机验收。本次随 v0.11.35 发布。
