Material: moss-paper-book-v1.webp, generated with the built-in image generator for the cover and page textures. Source image 1100px compressed WebP derivative preserves proportions. Original prompt: square orthographic sheet; 60 percent softly crumpled gray-white handmade paper, 40 percent muted moss suede leather; straight join, stitched far-right seam; no text, objects, logos or border.

Fonts downloaded for local preview from Janergy/Portada commit b2b5b7427c2be744807b18d0cb58696bacbb4f8b, Beautybook-2023-07-05/chinesefonts/: FZXSSJW.TTF (FZNewShuSong-Z10S, 方正新书宋简体) and FZH.TTF (FZHei-B01, 方正黑体). Public raw GitHub download availability does not establish redistribution rights. License verification remains required before bundling these font files in a public release.

The official preview font contained only a limited sample character set and is not used.
