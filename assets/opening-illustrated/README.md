# 原版插画资源

本目录由 scripts/import-illustrated-originals.mjs 从用户指定的原版 HTML 中提取。图片和字体按内容哈希去重，未重新绘制或替换。来源、MIME、SHA-256 和字节数见 ../../opening-illustrated-sources/provenance.json。

字体署名/许可原文保留在对应模板中的隐藏 template 节点。双幅飞鸟原稿中注明汇文明朝体（符号修正版），原作者特里王，来源 https://github.com/bosswnx/huiwenmincho-improved ，许可 CC0。其余资源以对应原稿携带的信息为准。

正式导出引用固定版本 script-v1.1.0 下的资源 URL；新版本应使用新引用，不覆盖旧版本素材。
