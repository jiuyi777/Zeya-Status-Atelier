# 暖蜜色和纸胶带

使用内置 image_gen 生成，透明背景。用于拼贴手账的标题纸与简介纸固定胶带，保留撕边和纸纤维；WebP 独立引用，显示时保持比例，轻微透明。

## Prompt

Use case: product-mockup. Asset type: isolated transparent-background washi tape cutout for an editable travel scrapbook web interface. Create ONE horizontal strip of real pale honey-beige rice-paper masking tape, approximately 4:1 width to height, isolated in the center with modest transparent margins. Top-down orthographic macro photography, lying flat, organic hand-torn irregular edges at both ends, lightly uneven long edges, fine visible paper fibers, subtle creases and soft mottled translucent adhesive texture. The tape itself is semi-transparent so the background beneath it can show through. Warm pale amber and oatmeal cream, neutral warm brown fibers; no green, no gray cast. Gentle even light, no large cast shadow. Refined realistic tactile stationery. No text, no graphics, no diagonal stripes, no checkerboard drawn into the picture, no notebook, no surrounding objects. Output actual alpha transparency around the tape and some translucency through the tape. The object should occupy most of the canvas width and be legible displayed at 110 by 30 CSS pixels.
